Bebas Neue - Fuente para Títulos (h1-h6)

Usada exclusivamente para títulos y headings (h1, h2, h3, h4, h5, h6). No usar para texto regular.

H1 - Título Principal

H2 - Subtítulo

H3 - Sección

H4 - Subsección

H5 - Título pequeño
H6 - Título más pequeño

Nota: Bebas Neue se aplica automáticamente a todos los elementos h1-h6. El texto regular (como este párrafo) usa Poppins.
